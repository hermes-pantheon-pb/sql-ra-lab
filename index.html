⚡ O Pipeline Mental de Execução de uma Consulta SQL

Para nunca depender de gravar fórmulas, memorize como o banco de dados realmente processa sua consulta de dentro para fora:

1
FROM & JOIN R × S, R ⨝ S

O banco carrega as relações base e faz as junções necessárias para montar o universo inicial de dados.

⬇
2
WHERE σ_{condição}

Filtra as linhas individuais. Linhas que não atendem à condição são descartadas antes de qualquer agregação.

⬇
3
GROUP BY _{G}γ_{F}

Divide as linhas restantes em grupos (baldes) com base nos valores das colunas especificadas.

⬇
4
HAVING σ_{agrupamento}

Filtra os grupos inteiros formados pelo GROUP BY usando os resultados das funções de agregação (ex: COUNT > 2).

⬇
5
SELECT π_{colunas}

Aplica a projeção final: calcula expressões, aplica funções de agregação e seleciona apenas as colunas pedidas.

⬇
6
ORDER BY & LIMIT τ_{ordem}, LIMIT n

Ordena o conjunto final de resultados e trunca para o número especificado de linhas.
